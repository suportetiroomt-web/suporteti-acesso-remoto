# Avisos de terceiros

## RustDesk 1.4.9

Este projeto incorpora, sem modificação, o executável oficial do RustDesk 1.4.9 para Windows x86-64.

- Projeto: https://github.com/rustdesk/rustdesk
- Código-fonte da versão: https://github.com/rustdesk/rustdesk/tree/1.4.9
- Release: https://github.com/rustdesk/rustdesk/releases/tag/1.4.9
- Licença: GNU Affero General Public License v3.0
- SHA-256 do executável incorporado: `EAEDEB0088E687BF46F7C46A9C6EA5493CE51F3134DFD6ACBEDB47B5B9136274`

O executável oficial mantém sua própria assinatura digital. A configuração usada para conectá-lo ao servidor privado está codificada no nome do arquivo temporário criado pelo inicializador e é visível no código-fonte.
